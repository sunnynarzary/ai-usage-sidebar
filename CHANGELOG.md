# Changelog

## 0.1.1

- Usage bars turn yellow at 80% and red at 100% again, as in the original panel.
- Reset times show days when a reset is at least a day away (for example "5d 21h" instead of "141h 34m").
- Reset times keep the correct unit at minute, hour, and day boundaries, including seconds remainders.
- Claude model rows show safe per-model names, including Fable, Opus, and Sonnet.

## 0.1.0

- Imported the installed three-provider sidebar as a baseline.
- Added per-tool consent, source-specific Cursor consent, visibility settings, read-only credential readers, safe error states, and fixed vendor request origins.
- Added unit tests, packaging metadata, and a Windows smoke checklist.
